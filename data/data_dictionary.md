# Data dictionary

One row per patient. All values are from routine clinical care; `id` is a
sequential de-identified number with no external meaning. Empty cells denote
values that were not measured. AUC0-24h is **not** an input column: the code
recomputes it from the measured concentrations by the linear trapezoidal rule
(AUC0-12h x 2), exactly as described in the article.

| Column | Description | Unit / coding |
|---|---|---|
| `id` | De-identified patient number | 1..98 |
| `daily_dose` | Maintenance dose regimen | mg/day (100 or 200) |
| `Age` | Age | years |
| `Sex` | Sex | 1 = male, 0 = female |
| `BMI` | Body mass index | kg/m^2 |
| `APACHE` | APACHE II score at ICU admission | score |
| `SOFA` | Sequential Organ Failure Assessment score | score |
| `BUN` | Blood urea nitrogen | mmol/L |
| `SCr` | Serum creatinine | umol/L |
| `CrCl` | Creatinine clearance (Cockcroft-Gault) | mL/min |
| `ALT` | Alanine aminotransferase | U/L |
| `AST` | Aspartate aminotransferase | U/L |
| `ALP` | Alkaline phosphatase | U/L |
| `GGT` | Gamma-glutamyl transferase | U/L |
| `TBIL` | Total bilirubin | umol/L |
| `DBIL` | Direct bilirubin | umol/L |
| `IBIL` | Indirect bilirubin | umol/L |
| `TP` | Total protein | g/L |
| `ALB` | Albumin | g/L |
| `PT` | Prothrombin time | seconds |
| `C0` | Plasma concentration immediately before the 7th dose (trough) | mg/L |
| `C0.5`, `C1`, `C2`, `C3`, `C4`, `C6`, `C12` | Plasma concentration at the indicated time after the start of the 7th dose infusion | mg/L |

The seven covariates retained by LASSO in the article are `TBIL, CrCl, SCr, BMI, Age, SOFA, PT`;
the remaining covariates are candidates that were screened out (Table R9c).

## About `synthetic_patients.csv`

`data/synthetic_patients.csv` is a **fully artificial** dataset with the same
schema. It is generated by `src/00_make_synthetic_data.py` (seed 20261107) from
parametric distributions whose ranges are informed only by the aggregate
summary statistics published in the article — no real patient record was used,
permuted or perturbed. Missingness is introduced at exactly the counts reported
in Table R7a: `C0.5`/`C1`/`C3`/`C4`/`C6`/`C12` are missing in
6/4/4/3/5/8 of 98 patients, while `C0` and `C2` are never missing. The file
exists so that the entire pipeline can be run and inspected end-to-end without
access to patient data.

## Patient-level data access

The real patient-level dataset contains sensitive clinical information and is
covered by the approval of the institutional ethics committee, which does not
permit public redistribution. De-identified data are available upon reasonable
request, subject to review by the ethics committee and a signed data use
agreement — see the README.
